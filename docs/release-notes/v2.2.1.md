**TS Media chat 2.2.1**: a Discord-like chat look, hold-to-record voice messages and simpler updates.

### Highlights

- **New chat look.** Names, avatars and times above grouped messages, like Discord. Or pick Compact or TeamSpeak classic.
- **Hold to record.** Hold the mic in the chat input and let go to send; move away first to cancel.
- **One emoji button.** TeamSpeak's own emoji button opens the HD picker.
- **Updates without keys.** New GitHub releases reach everyone, each file checked against its SHA-256.
- **Installs itself.** This update installs itself from 2.2.0; your settings and cache are kept.

![TS Media chat 2.2.1 in the TeamSpeak 3 chat with the Cozy layout: names, avatars and times above the messages, a photo album grid with a caption and reactions, an inline video, a voice message and a reply](https://github.com/Metihttp/Teamspeak_Media_chat/raw/v2.2.1/docs/images/hero-light.png)

### Changed

- Voice messages go out as soon as you stop, always from TeamSpeak's own microphone; the voice hotkey and the Voice messages settings are gone.

### Fixed

- An emoji picked in an empty chat input could take TeamSpeak's grey placeholder along: now only the emoji goes in.
- A connection lost while recording could leave your microphone muted: now it is unmuted once you are back.
- Quitting TeamSpeak with the voice message window open could leave it running in the background: now it quits.

### Install or update

**On 2.2.0:** wait for the update offer, or use **Check for updates…** in the plugin menu.

**On 2.1 or older, or new here?** Close TeamSpeak, double-click the file above, then type `/tsmedia` in the chat.

### Known issues

- The 32-bit DLL is untested on a real 32-bit client.
- TeamSpeak may crash or hang when it quits, with or without the plugin: [workaround](https://github.com/Metihttp/Teamspeak_Media_chat/blob/main/docs/FAQ.md#teamspeak-crashes-or-hangs-when-i-quit).
