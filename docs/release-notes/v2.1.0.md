**TS Media chat 2.1.0**: a clearer chat, viewer and upload panel, easier to read in light and dark themes and easier to use from the keyboard.

### Highlights

- **Easier to read.** Higher-contrast previews, file cards and messages in light and dark themes.
- **Keyboard-friendly viewer.** Visible focus, a full-screen header with name and counter, and a shortcut overview.
- **Uploads you can follow.** Retry failed uploads, see queued files and the time left.

### Changed

- Previews react to hover and clicks, and say whether a file is waiting or downloading.
- Dropping and pasting files show clearly what will be sent; files post in the order chosen.
- Reorganised settings; animations follow the Windows "Show animations" setting.
- Clearer wording, file names without the random upload suffix, and error messages that say what to do next.

### Install or update

Download **TSMedia-2.1.0.ts3_plugin** below, close TeamSpeak, double-click the file and start TeamSpeak again. Your settings and cache are kept.

<details>
<summary>First time? Requirements and steps</summary>

TeamSpeak 3 Client 3.6.x on Windows 10 or 11 (not TeamSpeak 5 or 6). Your server group needs file transfer permissions: see the [server admin guide](https://github.com/Metihttp/Teamspeak_Media_chat#server-admin-guide).

1. Download **TSMedia-2.1.0.ts3_plugin** below.
2. Close TeamSpeak.
3. Double-click the file, click **Install** and answer **Yes** when TeamSpeak asks whether to activate the add-on.
4. Start TeamSpeak and type `/tsmedia` in the chat to check that the plugin is running.

</details>

### Known issues

- The 32-bit DLL is included but has not been tested on a real 32-bit client yet.
- On a default server the Guest group cannot upload; an admin has to grant `i_ft_file_upload_power`.
