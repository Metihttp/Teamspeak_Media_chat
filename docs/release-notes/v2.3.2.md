## ⬇️ [Download TSMedia-2.3.2.ts3_plugin](https://github.com/Metihttp/Teamspeak_Media_chat/releases/download/v2.3.2/TSMedia-2.3.2.ts3_plugin)

**For TeamSpeak 3, this is the only file you need.** Double-click it to install. The other files further down are used by automatic updates; ignore them.

**TS Media chat 2.3.2** fixes "File doesn't match what was sent" for pictures and files that were fine, above all on TeaSpeak servers.

### Highlights

- **No more false "doesn't match".** Files that were still uploading are no longer blocked as different files.
- **Messages wait for the upload.** Your message goes out once the server really has the whole file.
- **Receivers wait too.** An unfinished download waits for the sender's upload and loads again by itself.
- **Works with older senders.** Messages from people who haven't updated yet are handled as well.
- **Click to try again.** A file that didn't match can be tried once more with a click.

### Fixed

- Pictures and files sometimes showed *File doesn't match what was sent* for friends who opened them right away, while they were fine for the sender. TeamSpeak reports an upload as finished before all of it has reached the server, so the message arrived too early; on TeaSpeak servers the unfinished file failed the checksum. Now the sender's message waits until the server has the whole file (TS Media reads the end of the file back from the server to make sure), and a receiver who still gets an unfinished file sees *Waiting for the sender's upload…* until it is complete.

### Changed

- If a sender's upload never completes, the preview says *Download failed* with **Retry** instead of *File doesn't match what was sent*.
- The diagnostic info names each server's software (for example TeaSpeak on Linux), which helps with reports.

### Install or update

**On 2.2.x or 2.3.x:** it updates itself. Wait for the update offer, or use **Check for updates…** in the plugin menu. Your settings and cache are kept.

**On 2.1 or older, or new here?** Close TeamSpeak, double-click the file above, then type `/tsmedia` in the chat.

### Known issues

- The 32-bit DLL is untested on a real 32-bit client.
- TeamSpeak may crash or hang when it quits, with or without the plugin: [workaround](https://github.com/Metihttp/Teamspeak_Media_chat/blob/main/docs/FAQ.md#teamspeak-crashes-or-hangs-when-i-quit).
