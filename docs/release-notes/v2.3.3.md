## ⬇️ [Download TSMedia-2.3.3.ts3_plugin](https://github.com/Metihttp/Teamspeak_Media_chat/releases/download/v2.3.3/TSMedia-2.3.3.ts3_plugin)

**For TeamSpeak 3, this is the only file you need.** Double-click it to install. The other files further down are used by automatic updates; ignore them.

---

**TS Media chat 2.3.3** fixes a bug in 2.3.2 that disconnected you from TeaSpeak servers when you sent a file. Everything 2.3.2 fixed stays fixed.

### Highlights

- **No more disconnects on TeaSpeak.** Sending (and receiving) files on TeaSpeak servers keeps you connected again.
- **Still no false "doesn't match".** Your message still waits until the server really has the whole file.
- **Tested on a real TeaSpeak server.** The server needed 4 to 8 more seconds for the last bytes of a photo and a video after TeamSpeak said they were uploaded; the messages waited for them.

### Fixed

- With 2.3.2, TeamSpeak disconnected you from a TeaSpeak server right after you sent a file (the log says *parameter not found*), and the message didn't go out. To check that the server had the whole file, 2.3.2 asked the server for the file's size, and TeaSpeak answers that request in a way TeamSpeak can't read. TS Media no longer asks TeaSpeak servers (or any server that isn't TeamSpeak's own) for a file's size. It reads the end of the file back from the server instead, which tells the same thing.

### Changed

- The TeamSpeak log notes for each server whether file sizes are asked.

### Install or update

**On 2.2.x or 2.3.x:** it updates itself. Wait for the update offer, or use **Check for updates…** in the plugin menu. Your settings and cache are kept.

**On 2.1 or older, or new here?** Close TeamSpeak, double-click the file above, then type `/tsmedia` in the chat.

### Known issues

- The 32-bit DLL is untested on a real 32-bit client.
- TeamSpeak may crash or hang when it quits, with or without the plugin: [workaround](https://github.com/Metihttp/Teamspeak_Media_chat/blob/main/docs/FAQ.md#teamspeak-crashes-or-hangs-when-i-quit).
