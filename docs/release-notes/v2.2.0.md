**TS Media chat 2.2.0**: play audio in the chat, drag files out of it, keep the plugin up to date, and set things per server.

### Highlights

- **Audio in the chat.** Music and voice files play inline with a seek bar, one at a time.
- **Drag files out.** Drag a picture, video or file from the chat or the viewer to a folder or another app.
- **Data saver per server.** Pause automatic downloads everywhere or only on some servers.
- **Optional automatic updates.** Signed updates from GitHub, only after you agree.
- **Easier help.** Copy diagnostic info for a bug report, without file names unless you choose.

### Changed

- Settings are now in tabs: General, Sending, Receiving & playback, Servers, Privacy & updates.
- Server admins can create the "tsmediachat" server group with one click (Settings, Servers).
- Chat messages for files you send follow TeamSpeak's flood protection: they wait when TeamSpeak asks, instead of being lost.
- The plugin keeps its own log file (`plugins/tsmedia/logs`), used by the diagnostic info.

### Fixed

- A chat message that TeamSpeak never confirmed counted as sent: now it is reported, and Retry posts it again.

### Install or update

Download **TSMedia-2.2.0.ts3_plugin** below, close TeamSpeak, double-click the file and start TeamSpeak again. Your settings and cache are kept.
