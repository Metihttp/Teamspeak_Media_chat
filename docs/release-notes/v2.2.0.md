**TS Media chat 2.2.0**: captions, spoilers and albums, voice messages, replies, HD emoji, reactions and automatic updates.

### Highlights

- **One send window.** Caption, spoilers, albums, crop and draw, and a quality choice for videos.
- **Voice messages.** Record up to 5 minutes, listen, send; others play them in the chat.
- **Replies and HD emoji.** Reply with a right-click or Alt+Up; sharp emoji, a picker (Ctrl+E), any emoji as a reaction.
- **Play and drag.** Audio plays in the chat; drag any file out into a folder.
- **Automatic updates.** Signed updates from GitHub, only after you agree.

![TS Media chat 2.2 in the TeamSpeak 3 chat: a photo album grid with a caption, an inline video, a voice message and reactions](https://github.com/Metihttp/Teamspeak_Media_chat/raw/v2.2.0/docs/images/hero-light.png)

### Changed

- Dropping files opens the send window; hold Ctrl to send right away (Settings → Sending).
- Videos over 25 MB are compressed to 720p MP4 by default; *Original* skips that.
- Your channel sees that you use TS Media, and your reactions; turn either off in Settings → Privacy & updates.
- The update check asks once and stays off until you agree.
- Downloads are checked with SHA-256; admins can create a `tsmediachat` group in one click.

### Install or update

This is the first version with automatic updates; install it by hand once. Download **TSMedia-2.2.0.ts3_plugin** below, close TeamSpeak, double-click it and start TeamSpeak again. Settings and cache are kept.

<details>
<summary>First time? Requirements and steps</summary>

TeamSpeak 3 Client 3.6.x on Windows 10 or 11. Your server group needs file transfer permissions ([server admin guide](https://github.com/Metihttp/Teamspeak_Media_chat#server-admin-guide)).

1. Close TeamSpeak and double-click the downloaded file.
2. Click **Install**, then **Yes** to activate the add-on.
3. Start TeamSpeak and type `/tsmedia` to check that it runs.

</details>

### Known issues

- The 32-bit DLL is untested on a real 32-bit client.
- Reactions reach only people with TS Media who are online.
- Windows has no country flag emoji, so flags stay letters.
- Friends on 2.1 or older count as "without TS Media" in the send window.
- Voice recording and video compression depend on your hardware; please report problems.
